01 · AKSES

Login ke Kasir Bisa

Masuk menggunakan nama pengguna atau nomor WhatsApp dan password akun pemilik. Demi keamanan, pendaftaran akun dari halaman login tidak tersedia. Sesi login berlaku hingga 12 jam; gunakan tombol Keluar setelah selesai menggunakan kasir.

Sebelum pertama kali memakai versi profil, administrator perlu menerapkan migrasi D1 terbaru dari folder project dengan npm run d1:migrate:remote ke database yang terhubung ke website. Untuk membuat akun awal, siapkan secret KASIR_USERNAME, KASIR_PASSWORD (minimal 12 karakter), dan AUTH_SESSION_SECRET (minimal 32 karakter acak) pada environment Cloudflare Pages yang digunakan. Jangan memasukkan nilai secret ke kode atau membagikannya.

02 · AKUN

Mengubah profil dan password

  1. Buka menu hamburger (ikon tiga garis) lalu pilih Profil.
  2. Ubah nama pengguna atau pilih foto profil. Foto JPG, PNG, atau WebP akan diperkecil otomatis.
  3. Untuk mengganti password, isi password saat ini, password baru minimal 12 karakter, lalu ulangi password baru.
  4. Tekan Simpan perubahan. Sesi login pada perangkat lain akan berakhir jika nama pengguna atau password berubah.

03 · PERSIAPAN

Mengelola katalog produk

  1. Di halaman Kasir, tekan Tambah produk.
  2. Isi nama, barcode, kategori, harga, dan stok. Barcode harus unik untuk setiap produk.
  3. Foto bersifat opsional. Pilih foto JPG, PNG, atau WebP; foto akan diperkecil otomatis sebelum disimpan.
  4. Tekan Simpan produk. Produk akan muncul di katalog dan siap dipilih untuk transaksi.

Gunakan tombol Edit pada kartu produk untuk mengubah datanya atau fotonya. Tombol Hapus menghapus produk dari katalog.

Gunakan kotak pencarian atau filter kategori untuk menemukan produk. Klik kartu produk atau tekan Tambah untuk memasukkannya ke keranjang.

04 · PENJUALAN

Mencatat transaksi

  1. Pindai barcode dengan kamera, atau ketik barcode di kolom pemindai lalu tekan Cari. Jika kamera tidak tersedia atau izinnya ditolak, gunakan cara ketik.
  2. Jika barcode belum terdaftar, formulir produk akan terbuka dengan barcode tersebut terisi. Lengkapi data produk lalu simpan.
  3. Periksa isi keranjang. Sesuaikan jumlah dengan tombol tambah/kurang atau keluarkan barang yang tidak jadi dibeli.
  4. Jika pelanggan terdaftar sebagai member, centang Pelanggan member. Member mendapat diskon 10%. Non-member mendapat diskon 5% jika subtotal minimal Rp100.000.
  5. Masukkan uang yang diterima atau pilih nominal cepat. PPN 11% dihitung setelah diskon; jumlah pembayaran harus cukup untuk menutup total.
  6. Tekan Bayar, periksa ringkasan, lalu tekan Konfirmasi & bayar. Stok akan berkurang setelah transaksi berhasil disimpan dan suara konfirmasi akan diputar.

05 · LAPORAN

Melihat dan mengunduh rekap

  1. Buka halaman Rekap dari navigasi.
  2. Cari berdasarkan produk, waktu, atau nominal, atau pilih produk tertentu pada filter.
  3. Tekan Hapus filter untuk menampilkan semua transaksi lagi.
  4. Tekan Unduh CSV untuk menyimpan data yang sedang tampil. File CSV dapat dibuka dengan aplikasi spreadsheet.

06 · ANALISIS

Menggunakan Smart Insight

Buka Smart Insight untuk melihat ringkasan transaksi, produk terlaris, stok menipis, jam ramai, dan saran penjualan. Tekan Buat insight baru untuk memperbarui analisis.

Jika analisis gagal, data ringkasan yang tersedia tetap dapat ditampilkan. Pengaturan Gemini merupakan tugas administrator; jangan memasukkan atau membagikan API key di halaman kasir.

07 · PEMECAHAN MASALAH

Jika mengalami kendala

  • Kamera tidak dapat digunakan: izinkan akses kamera di browser atau ketik barcode secara manual.
  • Barcode sudah dipakai: setiap produk harus memiliki barcode yang berbeda. Periksa katalog sebelum menyimpan.
  • Produk tidak bisa ditambahkan: stok mungkin habis. Edit stok produk sebelum melanjutkan penjualan.
  • Pembayaran ditolak: pastikan jumlah uang yang dimasukkan sama dengan atau lebih besar dari total.
  • Data atau Smart Insight gagal dimuat: periksa koneksi internet. Jika tetap gagal, hubungi administrator website.
